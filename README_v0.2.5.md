# Flasher Studio v0.2.5 — браузерный CMSIS-DAP v2 и нативные проекты ESP Recovery

Сохранены UI 20, каталог 39 загрузчиков × 2 версии, интеграция Builder v0.2.6 и Bootloaders v0.2.1. Firebase и репозитории не меняются.

## Новое
- CMSIS-DAP v2 USB bulk / WebUSB, SWD, ARM ADIv5 MEM-AP: только STM32F103C8T6 / STM32F103CBT6. Выбирается в существующем меню подключения. Проверка ID и размера Flash, UID, защита записи, проверка чтением. Запись стирает Flash целиком, включая Recovery. После записи — ручной RESET. CMSIS-DAP v1 HID, другие STM32 и другие ядра не поддерживаются этим драйвером. Требуется совместимый USB-интерфейс с именем CMSIS-DAP; некоторые пробники могут не отображаться или не предоставлять это имя.
- ESP-IDF ZIP: добавление проверенной CSV и параметров в sdkconfig.defaults в копии проекта, только для однозначного корня и без существующего sdkconfig/конфликтующих настроек. Исходные файлы остаются неизменными.
- PlatformIO Arduino ESP32 ZIP: добавление CSV и board_build.partitions/board_upload.flash_size к выбранному простому environment. Наследование, дополнительные конфиги/скрипты, переменные и конфликтующие настройки требуют ручной адаптации. Существующий lock с другой конфигурацией может потребовать осознанного обновления.
- Перед сохранением OTA-сборки проверяются фактические сегменты из манифеста Builder, соответствие таблицы разделов, тип чипа, app-only BIN и размер слота. Если Builder не определил адреса, результат отклоняется. Нативная компиляция с этой новой разметкой ещё не испытана в GitHub. Это не разрешение полной записи поверх Recovery.

## Не завершено
Прямые браузерные UPDI, Urboot, Nordic DFU, J-Link и ST-LINK/V3 (доступны прежние локальные утилиты, не заменяют браузер); автоматическое перемещение STM32-программы в область Recovery (пока нужен заранее скомпонованный образ); аппаратные испытания всех драйверов. Не гарантируется совместимость всех USB-адаптеров с Android и Wi-Fi OTA в конкретном браузере. Никаких симуляций в приложении.

## Проверка и деплой для испытаний
```
npm install --ignore-scripts --no-audit --no-fund
npm run vendor
npm test
python -m unittest discover -s tests -p '*_test.py'
firebase deploy --only hosting:studio --project esp-flasher-byvovk
```
Не использовать для серийных устройств до проверки на тестовых платах. Старый ESP Flasher не затрагивается. Прежние ограничения см. README_v0.2.4.md и README_v0.2.3.md.
