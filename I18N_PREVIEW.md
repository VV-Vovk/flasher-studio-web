# Localization preview (RU / EN / DE)

Draft based on v0.2.62. Not ready for release. Adds local language preference, translations for initial static markup and navigation, localized static accessibility labels, and offline shell caching. Dynamic status messages, generated dialogs, protocol errors, compiler logs and live device controls still require explicit localization and regression testing. Do not merge or publish until safety warnings and device workflows are reviewed in all languages. Existing projects, firmware, device IDs, credentials and programming protocols must remain unchanged.
