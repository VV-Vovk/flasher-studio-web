# Flasher Studio v0.2.1 — расширение аппаратных драйверов

Основа: v0.2.0, UI 20. Builder v0.2.6, Bootloaders v0.2.0 и старый сайт ESP Flasher не изменены. В этой версии нет демонстрационной записи.

## Деплой

```sh
cd ~ && unzip -o Flasher_Studio_v0.2.1.zip && cd Flasher_Studio_v0.2.1 && npm install --ignore-scripts --no-audit --no-fund && npm run vendor && npm test && firebase deploy --only hosting:studio --project esp-flasher-byvovk
```

Токен GitHub должен иметь доступ к `VV-Vovk/flasher-studio-builder`, Actions и Contents read/write, Metadata read. Сборка npm и реальные API-запросы не проверены здесь. `npm run vendor` обязателен. Сохраняется прежнее IndexedDB. Для ZIP сборки, недоступного из-за CORS, предусмотрен ручной импорт.

## Новые возможности — реальные драйверы, ещё без аппаратных испытаний

- ST-LINK/V2, USB 0483:3748, API v2, SWD: STM32F103C8T6 и CBT6. Чтение PID, размера Flash, UID; остановка ядра перед записью, проверка защиты, полное стирание и запись половинными словами, readback. Не изменяет Option Bytes. После операции нужен ручной RESET; быстрый RAM flash loader не реализован. ST-LINK/V2-1, V3, J-Link, CMSIS-DAP пока не поддерживаются. Windows может потребовать WinUSB для WebUSB, Android — разрешение USB.
- STM32 USB DfuSe (0483:df11): STM32F401RBT6, STM32F411CEU6, STM32F042F6P6. Проверяет дескриптор внутренней Flash, PID, размер Flash, UID; стирает страницы и проверяет записанные блоки. Если ROM запрещает доступ к регистрам ID/UID, соединение отклоняется; совместимость этого строгого режима на плате не подтверждена. Без Read Unprotect или записи option bytes.
- USBasp (16c0:05dc), ISP: ATmega328/328P, полная запись HEX и readback, сигнатура, не меняет Fuse Bits при обычной записи. Полное стирание удаляет прежний загрузчик и может удалить EEPROM; состояние BOOTRST не меняется. Низкая скорость SCK / соответствующая перемычка программатора, питание цели и уровни напряжения должны быть корректны.
- Arduino Mega 2560 через STK500v2, Leonardo и Micro через AVR109/Caterina. Проверка сигнатуры, адресов, каждой записанной страницы. Caterina: ручной RESET и выбор bootloader-порта. Не обещает прямое подключение на Android, т.к. WebUSB CDC/Serial зависит от оборудования и браузера.
- RP2040 и RP2350 (ARM secure UF2): проверка заголовков, family ID, адресов блоков и ручное сохранение файла для копирования на BOOTSEL-диск. НЕ является автоматической физической записью или подтверждением её результата.

## Ручная установка кандидатов загрузчиков

Все пакеты Bootloaders v0.2.0 остаются `candidate`, автоматическая установка не разрешена. Только тестовые платы и осознанное подтверждение.

- Голый ATmega328/328P: в «Сборка → Установить загрузчик → Стандартный UART-загрузчик» выбрать точный профиль с тактированием. Загрузить соответствующий ZIP Urboot из приватного GitHub Release/Artifacts. Сверяются размер и SHA-256 пакета и файла, сигнатура, адреса HEX. USBasp записывает Flash, затем проверяет Fuse/Lock Bits. Настройки кварца и напряжения определяет пользователь, а не компилятор. В этой версии отдельный последовательный клиент urclock ещё не реализован.
- ESP32-C3/S3/C6: «Установить загрузчик → Выбрать из каталога», выбрать точный пакет по радиоинтерфейсам, объёму Flash и GPIO. Загрузить его ZIP вручную из CI. Проверяются SHA-256, CSV, роли и адреса образов, заголовки ESP, MAC, точный размер Flash, доступный security-info (только flags=0, crypt count=0 и точный chip ID), полная резервная копия перед стиранием. При неизвестной защите запись запрещена. Запись всех сегментов с readback. Пользователь подтверждает сохранение резервной копии, отсутствие конфликта GPIO, полное стирание. Автоматическое скачивание приватного Release и автоматическая компиляция под layout Recovery не готовы. Для ESP32 без суффикса, S2 и H2 установки пока нет. Реальная проверка запуска Recovery/BLE не выполнена.

## Пока не реализовано

UPDI, Urboot/urclock через UART, Nordic DFU/SWD, CMSIS-DAP/J-Link, прямой BOOTSEL USB transport, Wi-Fi OTA из PWA (текущий Recovery HTTP не имеет CORS, HTTPS-приложение не может гарантированно обращаться к нему), автоматическое скачивание и установка произвольных загрузчиков, STM32 custom UART Recovery и автоматическая перестройка linker/partition layout. Не выдаются за работающие функции. Не изменяет ограничения предыдущих ESP Serial / STM32 ROM UART / BLE OTA / AVR STK500v1.

## Проверка

`npm test`: 21 тест (11 новых, 10 прежних), тестовые протокольные ответы и проверки отказа до записи. Дополнительно проверены 15 реальных ESP ZIP и 6 Urboot ZIP из облачных сборок, запуск UI в мобильном Chromium с локально подставленными модулями, переходы в диалоги установки. Физические устройства, npm vendor bundle, GitHub API и Firebase в текущей среде не проверены. До работы с ценными устройствами обязательны реальные аппаратные испытания на тестовых платах. Сначала резервное копирование.
