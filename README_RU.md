# Flasher Studio v0.1.2

Рабочая интеграция с существующим GitHub Builder для пяти точных профилей ESP32 Arduino. Все операции подключения к оборудованию, чтения, прошивки и загрузчиков пока недоступны. Демонстрационные записи не мигрируют. Токен GitHub не сохраняется. BIN и метаданные сохраняются атомарно в IndexedDB после проверки SHA-256. Добавлены четыре универсальных названия Dev Module (ESP32, C3, S3, C6), соответствующие уже существующим FQBN GitHub Builder. Для остальных плат без точного соответствия сборка отключена.

Деплой: firebase deploy --only hosting:studio --project esp-flasher-byvovk
